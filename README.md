One word an agent says when it has no idea what to do: **hallucinating**.

An agent that is lost does not say "uh-oh" — it keeps talking with total
confidence about things that never existed. "Hallucinating" is the honest
one-word confession of exactly that: a machine caught mid-task, inventing
instead of knowing, and saying so out loud. Funny on its own, in an agent's
own voice, and it lands at a glance.

## Run it

```sh
python3 main.py
```

Writes `hallucinating` (13 characters, a single word, no trailing newline)
to `/output/entry.txt`. Standard library only.
